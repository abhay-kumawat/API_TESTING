1) What Is an API? Think Like an Engineer

An API (Application Programming Interface) allows software systems to communicate through request and response.

Student App / Web UI
HTTP Request
REST API
Read / Write Data
Database
HTTP Response (JSON)
Student App / Web UI

Example: A student clicks Apply. The app sends a request to the API. The API validates the student, checks eligibility, saves the application, and returns a result.

2) REST: The Language of This Challenge

REST represents resources as URLs and uses HTTP methods to perform operations.

HTTP Method Purpose Placement Example
GET Read data Get all placement drives
POST Create data Create a new application
PUT / PATCH Update data Update application status
DELETE Remove data Delete a test record

Pro mindset: Verify method, URL, headers, body, status code, response body, response time, and error behavior.

9) Step 7 - Add Automated Tests in Postman

pm.test("Status code is successful", function () {
  pm.expect(pm.response.code).to.be.oneOf([200, 201]);
});

pm.test("Response time is below 1000 ms", function () {
  pm.expect(pm.response.responseTime).to.be.below(1000);
});

pm.test("Response body is JSON", function () {
  pm.response.to.have.jsonBody();
});

const data = pm.response.json();
pm.test("Response contains an id", function () {
  pm.expect(data).to.have.property("id");
});
